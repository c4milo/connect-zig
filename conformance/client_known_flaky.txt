# The conformance cases the client may fail or pass, each group with its reason (decision 26).
# `*` stands for one part of a case's name.
#
# A Connect unary request in gzip or zstd fails as client_known_failing.txt says, when the
# reference server reads its head: a request under 1 KiB goes uncompressed. A cancel 5 ms after
# the send can land first, and then the server checks no coding and the case passes.
Client Cancellation/*/Protocol:PROTOCOL_CONNECT/*/Compression:COMPRESSION_GZIP/*/unary/cancel-after-close-send
Client Cancellation/*/Protocol:PROTOCOL_CONNECT/*/Compression:COMPRESSION_ZSTD/*/unary/cancel-after-close-send
#
# Over HTTP/1.1 the reference gRPC server answers a half-duplex stream's head once it read the
# first message, and Go's net/http then drops the rest of the request body: a handler cannot
# read the body after it wrote the head over HTTP/1.x (net/http, ResponseWriter.Write). The
# second message, when it arrives later, fails "http: invalid Read on closed Body". The client
# sends each message as a piece of its own (decision 18), so a busy machine can open that gap:
# the whole suite failed it in one run here, and under `taskset -c 0` it fails one run in four.
Client Message Size/HTTPVersion:1/Protocol:PROTOCOL_GRPC_WEB/*/*/(grpc server impl)/bidi-stream/half-duplex/all-requests-equal-to-client-limit
